# Custom C++ linter
#### Checks
- [ ] все члены класса начинаются с 'm_', исключая структуры
- [ ] все указатели начинаются с 'p' (может конфликтовать с предыдущей проверкой, скорее всего придется их комбинировать в одну)
- [ ] все методы класса начинаются с большой буквы
- [ ] имена классов CamelCase
- [ ] namespace CamelCase
- [ ] структуры snake_case
- [ ] enum CamelCase
- [ ] проверять Allman style
- [ ] проверять фигурные скобки после if, while, do, case и т.д
- [ ] названия меньше 3 букв
- [ ] примитивные типы с lowerCamelCase
- [ ] bool переменые не называть через отрицание
- [ ] все члены класса начинаются с m_, структуры исключение
- [ ] Названия функций должны содержать в себе глагол.
- [ ] не использовать тернарный оператор
- [ ] проверка override - уже есть, надо просто включить
- [ ] использовать списки инициализации - уже есть
- [ ] запрет других кастов, кроме static_cast - уже есть
- [ ] запрет c-style cast - уже есть
- [ ] запрет NULL - уже есть
- [ ] запрет кастомных шаблонов, т.е. объявления типа template...
- [ ] запрет namespace std::, кроме
	- numeric_limits
	- sqrt
	- min
	- max
	- sort
	- unique_ptr
	- make_unique
	- fill
	- atomic_int
	- atomic_bool
- [ ] запрет tuple unpacking
- [ ] инициализация списком разрешена только для ряда классов (надо как-то получать этот список из конфига)
- [ ] инициализации структур разрешена только через [designated initializers](https://en.cppreference.com/w/cpp/language/aggregate_initialization.html#Designated_initializers)
- [ ] проверять, что все файл предваряется определенным комментарием, который должен подаваться через конфиг
- [ ] проверять вложенность if-ов, каким-то образом определять, что if можно вынести наверх как guard-clause
- [ ] определения не должны быть в хедерах
- [ ] не инициализировать поля в теле конструктора, использовать списки инициализации либо дефолтное значение в объявлении класса
- [ ] запрещать деструктор с пустым телом
- [ ] запрещать любой каст кроме static_cast
- [ ] использование макроса assert запрещено. Вместо него использовать Q_ASSERT
- [ ] auto можно использовать только в случаях, когда в выражении есть название типа и очевидно, какого типа переменная.
- [ ] в каждом файле должен содержаться копирайт
